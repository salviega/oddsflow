# OddsFlow — brand kit

The full rationale (contrast figures, UI rules, SEO) lives in
[`spec/definicion/09_marca-y-seo.md`](../spec/definicion/09_marca-y-seo.md).
This file is the quick reference.

## The mark

The symbol is a **gate between two posts, over a flow**. The yellow bar is the
gate, and it is also the price you set: it sits at a level on the gauge and
holds. The flow passes only when it reaches that level. It reads as the
product's central argument — your money stays put until someone takes the
other side — and, at a glance, as an abstract ladder of prices.

- `logo.svg` / `logo-dark.svg` — horizontal: symbol and wordmark
- `mark.svg` / `mark-dark.svg` — symbol only
- `og-image.svg` — source of `apps/web/public/og-image.png` (1200 × 630)
- `apps/web/public/favicon.svg` — symbol on a Lock tile, for the tab
- `apps/web/public/icon-16.png` — simplified symbol (posts and gate, no flow) for 16 px

Use the `-dark` version on dark backgrounds: posts, flow and wordmark switch
from Lock to Spillway; the gate stays Gauge yellow.

## Colour

| Role     | Hex       | Use                                                    |
| -------- | --------- | ------------------------------------------------------ |
| Lock     | `#0F2B2E` | Main background; text on light surfaces                |
| Spillway | `#E7EAE4` | Text on dark surfaces; light surfaces                  |
| Gauge    | `#F2C12E` | The one accent: the price level, primary action, fills |
| Mist     | `#A9B8B5` | Secondary text on Lock                                 |
| Silt     | `#7D8F8C` | Borders, dividers, large metadata — not body text      |
| Yes      | `#2E9E57` | The YES side of a market, and only that                |
| No       | `#D2483E` | The NO side of a market, and only that                 |

Gauge is the only accent. Yes and No are reserved for the two sides of a
market — never decoration, never success/error states — and always come with
the word YES or NO next to them. Silt, Yes and No are under 4.5:1 on Lock:
use them for fills, borders and large text, never for body text. Errors use
Spillway text on a Silt border with a written explanation, not colour alone.

## Prices and amounts

A price is a level on a gauge. Always show it as a decimal between `0.00` and
`1.00`, two decimals, tabular figures. The implied probability, when shown,
goes next to it in Mist (`0.20 · 20%` in tables, `0.20 (20%)` in prose).

Amounts are in sUSDS, two decimals, thousands grouped, unit always shown:
`1,000.00 sUSDS`. The dollar value is a secondary reference in Mist
(`≈ $1,052.40`), never the number that gets signed.

## Clear space

Leave around the logo a margin equal to the gap between the two posts.
Minimum size: 16 px for the symbol (use the simplified icon), 96 px wide for
the horizontal logo.

## What not to do

- Do not rotate, tilt or apply gradients to the symbol
- Do not move the gate below the flow or remove the posts
- Do not recolour the gate green or red: it is a price, not a side
- Do not set long text in Gauge on Lock or on Spillway; Gauge is for
  thick elements and short labels
- Do not place the logo over images without a contrast layer

## Type

**Barlow** for everything — a grotesk drawn from highway and public-works
signage, which fits a product built around gates and flows. Weights: 400 for
body, 500 for labels and data, 600 for headlines and the wordmark. Use
`font-variant-numeric: tabular-nums` on every price, amount and balance.
Licensed under the SIL Open Font License (`Barlow-OFL.txt`); the web loads it
with `next/font`.

The wordmark is Barlow SemiBold, lowercase, 36 px, outlined to paths in the
logo files so it renders without the font installed.

## Voice

Plain words, named after what the user does, not how the protocol works.

| Say                | Not                        |
| ------------------ | -------------------------- |
| Order              | Strategy, position, ship   |
| Filled             | Executed, matched on Aqua  |
| Available balance  | Virtual balance            |
| Expires            | Deadline, docked           |
| Cancel order       | Dock                       |
| Claim              | Redeem positions           |
| Invalid result     | INVALID outcome token      |

## Files

Design sources live here; what the site serves lives in `apps/web/public/`:

```
brand/            logo.svg  logo-dark.svg  mark.svg  mark-dark.svg  og-image.svg
apps/web/public/  favicon.ico  favicon.svg  icon-{16,32,48,180,192,512}.png
                  icon-maskable-512.png  og-image.png (1200 × 630)
```

The web manifest, `robots.txt` and `sitemap.xml` are generated by Next from
`apps/web/src/lib/site.ts`, which is the one place the title, description and
Open Graph copy are written.

To regenerate `og-image.png` after editing `og-image.svg`, render it with
Barlow available to fontconfig:

```sh
rsvg-convert -w 1200 -h 630 brand/og-image.svg -o apps/web/public/og-image.png
```
